# 위협 모델

두리가 무엇을 지키고, 무엇을 막고, **무엇은 막지 못하는지**를 솔직하게 적어요. 기능이 붙을 때마다 갱신해요.

> 현재 단계: **M0~M1 (개발 초기)**. 아래 표의 "상태" 열은 지금 실제로 구현된 것과 계획만 있는 것을 구분해요. 계획을 구현된 것처럼 말하지 않아요.

## 1. 지키는 것

| 자산 | 설명 |
|---|---|
| 사용자의 돈 | 결제, 예약 확정, 수수료가 생기는 취소 |
| 사용자의 관계 | 메시지·메일·글을 사용자 이름으로 보내는 일 |
| 계정과 로그인 상태 | 브라우저에 로그인된 서비스, AI 구독 |
| 대화와 기록 | 부탁 내용, 한 일, 화면 캡처, 허락 내역 |
| 사용자 PC | 파일, 설치된 프로그램 |

## 2. 신뢰 경계

```
[사용자] ─ 폰(M6) ─ 중계 서버(M6, 신뢰하지 않음) ─┐
                                                  ▼
[사용자 PC] ── 두리 앱·본체 dool2d (신뢰) ── 로컬 API 127.0.0.1 + 토큰
                  │
                  ├── 에이전트(Claude Code / Codex): 반쯤 신뢰
                  │     └ AI 판단은 틀릴 수 있고, 웹페이지 내용에 속을 수 있다
                  ├── 두리 도구(MCP) → 승인 게이트 → 브라우저·PC 제어
                  └── 웹페이지·외부 앱의 내용: 신뢰하지 않음
```

핵심 가정: **AI 에이전트를 믿지 않아요.** AI는 실수하고, 웹페이지에 숨은 지시(프롬프트 주입)에 속을 수 있어요. 그래서 안전은 AI의 판단이 아니라 코드(도구 제한과 승인 게이트)로 지켜요.

## 3. 위협과 대응

| # | 위협 | 대응 | 상태 |
|---|---|---|---|
| T1 | AI가 셸·파일·웹 기능으로 게이트를 우회 | 에이전트 내장 도구를 끄고 두리 도구만 허용. 시작 시 도구 목록 검사, 실행 중 위험 항목 감지 시 중단 ([ADR 0003](../decisions/0003-dool2-tools-only.md)) | ✅ 구현 |
| T2 | 웹페이지의 프롬프트 주입으로 결제·연락 시도 | 돈 내기·연락하기 등급은 사용자 승인 없이는 실행 불가. 등급은 AI가 아니라 두리가 판단. 승인하면 AI가 아니라 **본체가 그 버튼 하나만** 누르고, 누르기 직전 버튼 글자·주소가 승인 때와 같은지 다시 확인. 한 번만, 10분 안에만 유효. AI가 적은 금액은 틀릴 수 있어 승인 카드에 실제 화면 캡처를 함께 보여 줌. 승인 주소는 화면용 토큰으로만 부를 수 있음 | ✅ PC 승인 (폰 서명은 M6) |
| T3 | 범용 클릭으로 결제 버튼을 누름 | 클릭 직전 요소 글자·URL·스킬 표시로 위험 판단, 하나라도 위험하면 위험. 결제 도메인 요청 차단. **본체가 버튼 글자(결제·구매·주문·보내기·삭제 등)와 결제 단계 주소를 보고 위험하면 AI는 누를 수 없고 승인 요청(T2)이나 사람에게 넘기기만 가능.** 결제 단계 페이지에서는 Enter·제출도 막음. 사이트 확인 창(confirm)의 [확인]도 창 글(주문·예약·결제·보내기·삭제 등)과 주소로 같은 판단을 하고, 위험하면 승인을 받아 본체가 그 창만 누름(누르기 직전 창 글이 같은지 확인). 알림(alert)은 확장이 바로 닫고 글만 AI에게 알림. 비밀번호 칸 입력은 확장이 거절 | ✅ 구현 (네트워크 가드는 나중) |
| T4 | 다른 프로그램이나 웹페이지가 로컬 API 호출 | 127.0.0.1에만 열고, 실행마다 새로 만든 토큰 필요(시간 일정 비교) | ✅ 구현 |
| T5 | 다른 프로그램이 두리 도구(MCP)를 직접 호출 | 본체가 켤 때마다 화면용과 다른 **도구 전용 토큰**을 만들어 도구 서버에만 넘김. 이 토큰으로는 `/api/tools/*`만 부를 수 있음 | ✅ 구현 |
| T6 | Claude 구독 자격 증명 유출 | 두리는 Claude 로그인 정보·토큰을 읽거나 저장하지 않음. 로그인 버튼은 공식 `claude auth login`을 띄우고 붙여 넣은 코드를 그 프로그램에 전달만 하며, 로그인 과정의 출력은 끝나면 버림 ([ADR 0002](../decisions/0002-official-agent-binaries.md)) | ✅ 구현 |
| T7 | 대화 기록 유출 | 기록은 사용자 PC의 SQLite에만 저장. 원격 전송 없음 | ✅ 구현 |
| T7-1 | 문제를 찾으려고 남기는 일한 기록(연결·도구·답 한 차례, 멈춘 화면 그림)이 쌓이거나 새어 나감 | 사용자 PC의 데이터 폴더(`logs/`)에만 남기고 원격 전송 없음. 글 기록 7일·화면 그림 3일이 지나면 지우고, 전체 40MB를 넘으면 오래된 것부터 지움. 아이디·비밀번호·인증번호와 도구 입력값(찾는 말 등)은 적지 않고, 글에 섞인 이메일·긴 숫자, 칸에 든 값, 주소의 물음표 뒤는 가림. 본체 API(`/api/logs`, 화면용 토큰)로만 읽음 (`apps/daemon/src/journal.ts`) | ✅ 구현 |
| T8 | 캡차·본인인증 자동 우회로 계정 정지 | 우회하지 않고 사람에게 화면을 넘김(확장이 캡차 화면을 알아채면 AI에게 알리고, `browser_handoff`로 두리 탭을 사용자 앞에 띄움. 앱에 [다 했어요]). 우회 코드·스킬은 받지 않음 | ✅ 구현 |
| T9 | 중계 서버가 내용을 엿보거나 바꿈 | 종단 간 암호화(X25519 → AES-256-GCM, 머리는 AAD로 묶어 바꾸면 열리지 않음), 순번으로 재전송 차단, 승인은 PC가 폰 Ed25519 공개키로 직접 검증. 순방향 비밀성은 없음 ([ADR 0012](../decisions/0012-phone-link.md)) | 🚧 M6 (암호화·페어링·서명 확인 구현, 폰 앱 진행 중) |
| T10 | 허락 화면 위조(보이는 내용과 서명 내용이 다름) | 서명 대상은 PC가 만든 요청 해시. 돈 내기는 네이티브 앱 서명을 우선 | 🗓 M6 |
| T11 | 변조된 설치 파일·업데이트 | GitHub Actions에서만 빌드, 코드 서명·공증, 빌드 출처 증명, 서명된 업데이트만 설치 | 🗓 M5 |
| T12 | 악성 스킬 기여 | 스킬은 게이트를 끌 수 없음. 등급 표기·금지 지시 CI 검사, 메인테이너 리뷰 | 🗓 M4 |
| T14 | 부품 설치 중 변조된 파일 설치 | Claude Code는 공식 배포 서버(HTTPS)에서 받고 매니페스트의 SHA-256·크기가 맞을 때만 공식 `claude install`을 실행(매니페스트 서명 검증은 아직 안 함). Codex는 npm 공식 레지스트리에서 받고 **두리 코드에 고정한 SHA-512**와 맞을 때만, 종량제 실행기는 고정 버전 릴리스의 `SHA256SUMS`로 확인. Chrome은 Google 공식 주소에서 받고 맥은 코드 서명·팀 ID·Gatekeeper 공증, 윈도우는 Authenticode 서명자(Google LLC)를 확인한 뒤에만 설치 | ✅ 구현 |
| T13 | 의존성 공급망 공격 | 잠금 파일 고정, CI 액션 커밋 고정, 의존성 알림, Codex 버전 고정 | ✅ 일부 |
| T15 | 금고에 저장한 로그인 정보가 엉뚱한 사이트에 입력됨 | AI는 값을 받지 않고, 두리 본체가 현재 주소와 저장된 사이트가 같을 때만 비밀번호 칸에 직접 입력. 사이트는 origin(https)만 저장해 비슷한 주소(`shop.example.phish.io`)에는 채우지 않음. 본체가 확인하고 확장이 채우기 직전 한 번 더 확인. 채운 칸은 페이지 읽기에서 값 대신 '금고로 채워짐'. 금고 API는 화면용 토큰으로만, 비밀번호는 돌려주지 않음. 마지막 사용 시각 기록. 사이트별 '물어보고 채우기'는 M3. 대화 안 로그인 카드로 받은 값도 AI를 거치지 않고 금고로만 가고, 사이트는 두리 탭의 지금 주소로만 정해짐(AI가 못 정함) ([ADR 0011](../decisions/0011-login-vault.md)) | ✅ 구현 |
| T17 | 다른 프로그램이 브라우저 다리(로컬 소켓)에 붙어 확장에 명령 | 본체가 켤 때마다 새 토큰을 만들어 사용자만 읽을 수 있는 파일(0600)에 두고, 첫 줄로 토큰을 보내지 않으면 끊음. 소켓 파일도 0600. Chrome은 등록 파일의 `allowed_origins`에 적힌 두리 확장에만 호스트를 띄움 | ✅ 구현 |
| T18 | 폰 알림(웹 푸시)으로 내용이 새거나, PC가 엉뚱한 주소로 요청하게 됨 | 알림 내용은 폰 브라우저만 풀 수 있게 RFC 8291로 암호화(푸시 서비스도 못 읽음). 구독은 페어링된 폰의 암호화된 메시지로만 받고, 알려진 푸시 서비스의 https 주소로만 보냄. 410이면 구독을 지움 | ✅ 구현 |
| T19 | 원격 화면으로 사용자 탭을 엿보거나 조작 | 두리가 사람에게 넘긴 탭(로그인·캡차 넘기기, 폰에서 서비스 연결하려고 연 탭)만, 넘긴 뒤 30분 동안만 화면·입력을 허용(본체와 확장이 각각 확인). 화면은 PC·폰만 여는 암호문이고 중계 서버는 쌓아 두지 않음. 원격으로 넣은 글자는 대화 기록·AI에 남지 않음. 누를 수 있는 키도 몇 가지로 제한 | ✅ 구현 |
| T20 | AI가 PC 앱으로 셸·설정·파일을 다루거나, 앱 화면의 지시(프롬프트 주입)로 메시지를 보냄 | 사용자가 허용한 앱만 다룸(처음 쓰는 앱은 승인). 터미널·시스템 설정·Finder는 기본으로 막고 허용 요청도 받지 않음. 브라우저·비밀번호 관리자·두리 자신은 도우미도 거절. 보내기·결제·삭제 버튼과 메신저 Enter는 승인 뒤 본체가 다시 읽어 같은 버튼일 때만 누름. 비밀번호 칸 값은 읽지도 넣지도 않음. 화면이 잠겨 있으면 하지 않음 | ✅ 구현 (맥) |
| T16 | 종량제 모드에서 API 키 유출·과금 폭주 | 키는 OS 키체인에 두고 실행할 때만 환경 변수로 전달, 월 한도를 넘으면 멈추고 물음. 회사 PC의 시스템 전체 관리 설정은 두리가 막을 수 없음 ([ADR 0010](../decisions/0010-pay-as-you-go-opencode.md)) | 🗓 M1+ |

## 4. 막지 못하는 것

- **이미 악성코드에 감염된 PC.** 같은 사용자 권한으로 도는 악성코드는 두리의 메모리, 기록, 브라우저를 볼 수 있어요.
- **사용자가 내용을 확인하지 않고 허락한 경우.** 두리는 허락 화면에 무엇을·어디서·얼마인지·취소 조건을 또박또박 보여 주지만, 최종 판단은 사용자 몫이에요.
- **AI 회사 쪽 문제.** Claude Code·Codex 서비스 자체의 장애나 보안 사고.
- **서비스 약관.** 자동화를 금지하는 서비스도 있어요. 두리는 사람 속도로 사용자 대신 조작하지만, 약관 판단은 서비스마다 달라요. 스킬에 알려진 제한을 적어요.

## 5. 고정된 보안 테스트

다음 테스트는 지우거나 약하게 만들 수 없어요. 바꾸려면 이 문서를 함께 고치고 이유를 적어야 해요.

- 에이전트가 두리 도구 밖의 도구를 알리면 실행이 멈춘다 (`packages/agent-claude`, `packages/agent-codex`)
- 토큰 없이 로컬 API를 부르면 거절된다 (`apps/daemon`)
- (M3) 허락 없이 돈 내기·연락하기 도구가 실행되면 테스트가 실패한다 (`packages/gate`)

취약점을 찾으셨다면 [보안 정책](../../SECURITY.md)에 따라 비공개로 알려 주세요.
