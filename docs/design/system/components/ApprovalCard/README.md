# ApprovalCard
The stop sign before anything that spends money or sends a message. The heaviest element on any screen it appears in.

- Header on `butter-soft` with the asking 두리 and one short question ("결제할까요?", "이 메일 보낼까요?").
- Body: key–value rows separated by hairlines; the last row is the total in bold.
- Actions: `거절` (secondary, 1/3) and `승인하기` (primary, 2/3) with a fingerprint/Face ID glyph. Approval is completed by biometrics on the phone.
- On mobile it is a bottom sheet (`radius-xl` top corners). On PC it appears inline in the chat and as a push to the phone.
- Never auto-approve, never pre-check "always allow" for payments.
