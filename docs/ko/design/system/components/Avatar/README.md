# Avatar
두리, the mint outlet-face mascot of dool², in six moods. Use the SVG files in assets/Character.

- Sizes: 24 (message head), 32 (status header, approval), 48 (mobile status), 96–120 (empty states). Never larger.
- One character per screen region; don't repeat it on every message.
- The outlet face (two slot eyes + ground-hole mouth) is the existing dool² mascot. The companion dot top-right is the phone — 두리 = 둘이: soft mint = idle, mint with dashed orbit = working, butter ? = needs you, ink check = done, gray = asleep.
- Flat only: no shadow, outline, gradient or 3D.
