# StatusHeader
Top bar that answers two questions at a glance: is my computer connected, and what is 두리 doing right now.

- Avatar mood + name + one status line with a dot: working (mint + brand-text line, e.g. '우리 집에서 일하는 중') / connected (mint dot) / asleep (gray) / needs you (butter).
- The status line names the device ("MacBook") and the site when working.
- Mobile: the screen's top bar. PC: top of the chat column.
