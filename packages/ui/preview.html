원칙

화면이 귀여운 게 아니라, 두리가 귀여운 거예요.

  • 하는 일이 보여야 믿는다두리의 화면과 단계 기록으로 지금 어디서 뭘 하는지 보여 줘요.
  • 돈과 메시지는 사람이 누른다결제·전송은 노랑 승인 카드에서 멈추고 폰에서 승인해요.
  • 민트는 두리의 색캐릭터, ², 일하는 중 점에만. 버튼과 내 말풍선은 ink예요.
  • 카드보다 선1px 선과 회색 면으로 나눠요. 그림자는 떠 있는 것에만.
  • 상태는 색으로 약속한다민트 = 일하는 중, 노랑 = 당신이 필요해요, ink 체크 = 끝.
