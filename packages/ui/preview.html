PC 앱·폰 앱·Chrome 확장이 같이 쓰는 부품이에요. packages/ui/ui.css 하나에 있고, 각 앱은 화면 배치만 따로 가져요. 새 화면을 만들 때는 여기 있는 부품부터 써요.

원칙

"AI가 만든 화면" 같지 않게. 꾸밈을 더하기보다 덜어 낸다.

  • 상자보다 선나눌 때는 1px 선, 감쌀 때만 카드. 상자 안에 상자를 넣지 않아요.
  • 색보다 회색 단계중요한 정도는 글자 진하기 네 단계로 나눠요.
  • 색은 둘만두리 초록은 연결·진행·완료, 주황은 승인·직접 해 주세요.
  • 상태는 점 하나색 배지·이모지 대신 7px 점과 회색 글씨.
  • 글자 대신 선 아이콘›, ✓, ← 같은 글자를 아이콘으로 쓰지 않아요.

글자는 --ink → --ink2 → --sub → --faint 순서로 덜 중요해져요.
