# @dool2/ui — 두리 디자인 시스템

PC 앱·폰 앱·Chrome 확장이 같이 쓰는 토큰과 부품이에요. CSS 파일 하나(`ui.css`)이고, 각 앱은 화면 배치만 자기 `style.css`에 둬요.

- `ui.css` — 토큰(색·모양·글꼴)과 부품
- `fonts.css`, `fonts/` — Pretendard 가변 글꼴 ([SIL OFL 1.1](fonts/OFL.txt)). PC 앱·확장에만 넣고, 폰은 기기 글꼴을 써요
- `preview.html` — 모든 부품을 한 화면에 모은 견본. 브라우저로 바로 열어 보면 돼요
- `copy.mjs` — 앱 빌드가 `ui.css`(와 글꼴)를 자기 `dist`로 복사할 때 써요

```js
import { copyUi } from '../../../packages/ui/copy.mjs'
copyUi('dist/renderer', { fonts: true }) // PC 앱·확장
copyUi('dist') // 폰 앱
```

```html
<link rel="stylesheet" href="fonts.css" /> <!-- PC 앱·확장만 -->
<link rel="stylesheet" href="ui.css" />
<link rel="stylesheet" href="style.css" /> <!-- 앱의 화면 배치 -->
```

## 원칙

"AI가 만든 화면" 같지 않게, 꾸밈을 더하기보다 덜어 내요.

1. **상자보다 선.** 나눌 때는 1px 선(`--line`)을 쓰고, 감쌀 때만 카드를 써요. 상자 안에 상자를 넣지 않아요.
2. **색보다 회색 단계.** 중요한 정도는 글자 진하기 네 단계로 나눠요: `--ink` → `--ink2` → `--sub` → `--faint`.
3. **색은 둘만.** 두리 초록(`--duri`)은 연결·진행·완료, 주황(`--warn`)은 승인·직접 해 주세요. 파랑 링크, 빨강·노랑 배지는 쓰지 않아요.
4. **상태는 점 하나.** "준비됨" 같은 색 배지나 🔐·🙋 같은 이모지 대신, 7px 점(`.dot`)과 회색 글씨를 써요.
5. **글자 대신 선 아이콘.** `›`, `✓`, `←`, `＋` 같은 글자를 아이콘으로 쓰지 않아요. 24 격자, 선 굵기 1.6의 SVG(`svg.i`)를 써요.

그 밖의 규칙:

- 굵기는 400·500·600만 써요. 700 이상은 쓰지 않아요.
- 큰 제목은 자간을 좁혀요(-0.03em). 본문은 거의 그대로 둬요.
- 한국어는 낱말 단위로 줄을 바꿔요(`word-break: keep-all`, 바탕에 들어 있어요).
- 주소·코드·확인 숫자는 고정폭(`.mono`, `.kv dd.host`)으로 써요.
- 주 버튼(검정)은 화면에 하나만 둬요. 나머지는 `.btn-ghost`나 `.btn-text`를 써요.
- 문구는 평소 쓰는 말로 써요. 예를 들어 "허락" 대신 "승인", "잠긴 봉투" 대신 "암호화"라고 써요.

| 진행 단계  | `.worklog` (`li.done` `li.now` `li.next`)                                                                | 맡긴 일 카드, 대화 안의 일하는 중                      |
| 알림       | `.toast`                                                                                                 | 잠깐 뜨는 알림                                         |
| 앱 알림 줄 | `.msg.note`                                                                                              | 두리 앱이 대신 보낸 승인 결과 (대화 가운데 회색 한 줄) |

자세한 모양은 [preview.html](preview.html)을 열어 보세요.

## 새 화면을 만들 때

1. 부품이 이미 있는지 [preview.html](preview.html)에서 먼저 찾아요.
2. 앱의 `style.css`에는 배치(그리드·여백·위치)만 넣어요. 색·모서리·그림자는 토큰을 써요.
3. 두 앱 이상에서 쓰는 모양이 새로 생기면 `ui.css`로 올리고, `preview.html`에도 견본을 추가해요.
4. 화면을 캡처해서 원칙 다섯 가지에 어긋나는 게 없는지 봐요.
