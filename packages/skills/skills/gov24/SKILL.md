# 정부24 (gov.kr)

주민등록등본·초본, 각종 증명서 발급을 돕는 팁.

- **데이터 경로를 먼저 찾는다.** 사용자가 이미 로그인돼 있으면 그 세션으로 사이트 내부 조회/신청 요청을 그대로 호출한다. 화면을 하나씩 클릭하는 것보다 빠르고 덜 깨진다. 내부 요청을 못 찾을 때만 화면을 조작한다.
- 로그인은 간편인증(카카오·PASS 등)이나 공동인증서를 먼저 쓴다. 이 단계는 사람이 해야 하니 사용자에게 넘긴다(hand-off). 이미 로그인 상태면 다시 로그인하지 않는다.
- 아이디·비밀번호 로그인을 받는 서비스면 위 `login` 힌트가 그 필드를 짚어 주고, 금고가 비밀을 직접 채운다(AI는 비밀을 보지 않는다). 그래도 본인확인 단계가 뜨면 사용자에게 넘긴다.
- 발급 결과는 대개 PDF다. 인쇄/발급 버튼을 눌러 PDF로 저장한다.
- 본인확인(휴대폰 인증, 공동인증서 비밀번호 등 사람이 해야 하는 단계)은 사용자에게 넘긴다(hand-off). 우회하지 않는다.
- 문서 종류·주소·주민번호 뒷자리 표시 여부 같은 발급 옵션은 신청 전에 확인한다.
