# 쿠팡 (coupang.com)

주문·배송 조회와 결제를 돕는 팁.

- **데이터 경로를 먼저 찾는다.** 로그인된 사용자 세션으로 주문 목록·배송 상태 조회 요청을 직접 부르면 화면을 넘기며 읽는 것보다 빠르다. 안 되면 화면을 읽고 조작한다.
- 주문 내역은 마이페이지 > 주문목록에 있다. 날짜 범위로 좁혀 찾는다.
- 배송 추적은 주문 상세의 배송조회에서 운송장으로 확인한다.
- 결제(돈이 나가는 단계)는 되돌리기 어려우니 반드시 승인을 거친다. 카드번호·비밀번호 같은 비밀은 AI가 다루지 않고 금고가 화면이나 보안 키패드에 직접 채운다.
- 로그인/본인확인 단계에서 캡차나 추가 인증이 뜨면 사용자에게 넘긴다(hand-off).
