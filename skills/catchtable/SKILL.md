# 캐치테이블

| 항목 | 내용 |
|---|---|
| 상태 | 검증됨(2026-11-17, 검색 → 날짜·인원·시간 → 예약금 안내까지. 결제는 하지 않음) |
| 주소 | 홈 https://app.catchtable.co.kr/ · 지역·가게 검색 결과 `https://app.catchtable.co.kr/ct/map/search-map?keyword=<검색어>&keywordSearch=<검색어>&serviceType=INTEGRATION` |
| 로그인 | 찾기·빈자리 보기·날짜·인원·시간 고르기는 로그인 없이도 된다. 예약금 결제부터 로그인 필요(휴대폰 문자 인증, 카카오·네이버·애플 간편 로그인) |
| 차단 위험 | 낮음 — 평소 Chrome으로 검색·예약 직전까지 막힘 없음 |
| 반복 조회 간격 | 같은 가게·날짜는 5분 이상. 빈자리 알림은 캐치테이블 자체 알림을 권한다 |
| 공식 API·앱 링크 | 일반 사용자용 공개 API 없음. 앱 '캐치테이블' |

## 할 수 있는 일

| 일 | 등급 | 비고 |
|---|---|---|
| 지역·가게 검색, 날짜별 빈자리 보기 | 찾아보기 | 로그인 없음 |
| 날짜·인원·시간·테이블 타입 고르기 | 채워 두기 | 예약금 화면 전까지 |

## 사용자에게 먼저 확인할 것

- 날짜(요일만 말하면 날짜로 바꿔서 확인), 시간, 인원, 지역
- 원하는 분위기·음식·가격대가 있으면

## 절차

### 1. 검색 결과 열기
- [찾아보기] 검색 결과 주소를 바로 연다: `https://app.catchtable.co.kr/ct/map/search-map?keyword=성수&keywordSearch=성수&serviceType=INTEGRATION` (성수 자리에 지역·가게 이름). 1~2초 뒤 가게 목록이 뜬다.
- [찾아보기] `/ct/search?keyword=…` 주소는 쓰지 않는다. 빈 화면만 나온다.
- [찾아보기] 홈에서 찾을 때는 위쪽 검색칸 → 검색 화면의 입력칸에 지역을 넣고, 자동완성 줄(예: '성수 461 서울특별시')을 누른다.

### 2. 빈자리 보기
- [찾아보기] 가게마다 이름·별점·지역·음식 종류·가격대(예: '점심 저녁 동일가 1 - 4만원')·'최대 ○명 예약 가능' 아래에 날짜 칸이 줄지어 있다: '11.27 (금) 예약 가능', '11.23 (월) 휴무', '예약 마감'.
- [찾아보기] 원하는 날짜가 '예약 가능'인 가게만 후보로 고른다. 후보 2~3곳을 먼저 보여 주고 고르게 한다.
- [찾아보기] 목록은 굴리면 칸을 재활용한다. 굴린 뒤에는 다시 읽고 누른다. "둘레 글이 읽을 때와 달라졌어요"가 나오면 다시 읽고 같은 가게의 칸을 다시 찾는다.

### 3. 날짜·인원·시간 고르기
- [채워 두기] 고른 가게의 날짜 칸을 누르면 날짜·인원·시간 창이 뜬다(주소에 `selectedDate=261127`처럼 붙는다). 달력에서 그 날짜가 골라져 있다.
- [채워 두기] 인원 라디오('4명' 등)를 누른다. 기본은 2명이다. 누른 뒤 '선택됨'인지 확인한다.
- [채워 두기] 시간 버튼('오후 7:30')을 누른다. 그 인원·날짜에 없는 시간은 버튼이 없다.
- [채워 두기] 가게에 따라 다음 단계가 이어진다: '테이블 타입 선택'(홀·홀(커튼)·룸 라디오, '비활성'은 못 고름) → '다음', '추가 상품'(꽃다발·위스키, 고르지 않고 '다음').

### 4. 예약금 화면에서 멈추기
- [찾아보기] '예약금 안내'(1인당 예약금 × 인원, 환불 정책) 또는 '예약금 결제 방법 선택'(예약금 0원 결제 / 예약금 결제)이 나오면 여기서 멈춘다.
- [돈 내기] 그 화면의 '다음', '0원 결제로 예약', 결제 버튼은 두리가 누르지 않는다. 가게·날짜·시간·인원·테이블·예약금·환불 정책을 정리해 승인을 받는다.
- [찾아보기] '예약금 0원 결제란?' 안내 팝업이 저절로 뜰 수 있다. 팝업 안 글은 그림이라 읽히지 않는다. '닫기'만 누른다. 같은 팝업의 '0원 결제로 예약'은 예약 확정이라 누르지 않는다.

## 결과 보고

- 후보: 가게 이름 · 지역 · 음식 · 가격대 · 원하는 날짜 빈자리 여부
- 예약 직전: 가게 · 날짜·시간 · 인원 · 테이블 타입 · 예약금(1인당 × 인원 = 합계) · 환불 정책(당일·1일 전 취소 환불 여부)

## 막힐 때

- 로그인 화면·휴대폰 문자 인증: 사람에게 넘긴다(`browser_handoff`).
- 원하는 시간 버튼이 없다: 그 시간은 마감이다. 앞뒤 30분 시간이나 다른 후보를 제안한다.
- 날짜 칸이 '예약 마감'·'휴무'뿐이다: 다른 날짜나 다른 가게를 제안한다.

## 하지 말 것

- 예약금 결제·예약 확정 버튼 누르기(승인 없이).
- 추가 상품(꽃다발·위스키) 담기 — 사용자가 따로 부탁할 때만.
- 같은 가게를 짧은 간격으로 계속 조회하기.
