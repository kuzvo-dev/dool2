# 두리 스킬

스킬은 두리가 특정 서비스(택배 조회, 기차 예매, 홈택스 등)를 **막히지 않고 끝까지** 처리하는 방법을 적은 문서예요. 코드가 아니라 문서라서 개발자가 아니어도 기여할 수 있어요.

- 라이선스: **CC BY-SA 4.0** ([LICENSE](LICENSE), [ADR 0008](../docs/decisions/0008-skills-cc-by-sa.md)). 레포의 코드(Apache-2.0)와 달라요.
- 두리는 일을 시작하기 전에 `skill_find`로 맞는 스킬을 찾고, `skill_read`로 읽은 뒤 따라요.

## 형식

서비스 하나 = `skills/<서비스-id>/` 폴더 하나예요. [`_template/`](_template/)를 복사해서 시작하세요.

| 파일 | 무엇 | 필수 |
| --- | --- | --- |
| `connect.json` | **연결 카드.** 연결 화면(목록·상세)에 보일 이름·도메인·분류·소개·대화 예시·할 수 있는 일 ([ADR 0014](../docs/decisions/0014-connect-cards.md)) | 예 |
| `SKILL.md` | **절차.** 두리가 그 서비스에서 막히지 않고 끝까지 하는 방법. 실제로 돌려 본 뒤 붙여요 | 아니요 |

### connect.json

| 칸 | 내용 |
| --- | --- |
| `id` | 폴더 이름과 같게. 영어 소문자·숫자·`-` |
| `name` | 화면에 보일 이름 |
| `site` | 도메인만, `https://` 없이 (예: `coupang.com`). 폰 권한(`device`)이면 생략 |
| `category` | `shopping` 쇼핑 · `grocery` 장보기·배달 · `fashion` 패션·뷰티 · `travel` 여행·숙소 · `flight` 항공 · `tickets` 예매·예약 · `media` 영상·음악 · `books` 책 · `social` SNS · `work` 업무 · `mail` 메일·일정 · `telecom` 통신 · `life` 생활 · `device` 휴대폰 |
| `how` | `browser` 사용자 Chrome에서 한 번 로그인 · `official` 공식 연동(준비 전엔 browser처럼) · `open` 로그인 없이 · `device` 폰 권한 |
| `login` | 연결할 때 하는 로그인 (예: `아이디·비밀번호`, `카카오·네이버 간편 로그인`). `browser`면 필수 |
| `summary` | 상세 화면 첫 문단, 한두 문장 |
| `example` | 대화 예시 하나: `ask` 사용자 부탁, `working` 일하는 동안 보이는 말, `reply` 두리의 답 |
| `abilities` | 할 수 있는 일 2~6개: `title` 짧은 이름, `say` 사용자가 할 법한 말(따옴표 없이), `tier` 권한 등급 |
| `signedIn` | (선택) 로그인한 사람에게만 보이는 말 1~5개 (예: `["마이쿠팡"]`). 연결할 때 이 말이 화면에 보이면 두리가 로그인을 마친 걸로 봐요. 없으면 `로그아웃`·`Logout` 같은 흔한 말로 확인해요 |

- "결제는 승인받고 해요" 같은 안내는 적지 않아요. `tier`가 `돈 내기`·`연락하기`인 일이 있으면 화면이 알아서 붙여요.
- 로고 파일은 넣지 않아요. 아이콘은 연결 화면이 `site`에서 받아 와요.
- 문구는 [두리 페르소나](../docs/persona.md) 말투로, 다른 회사 제품 이름은 넣지 않아요.

### SKILL.md

- 맨 위 `name`(폴더 이름과 같게), `description`(사용자가 말할 법한 표현 포함)
- 표의 **상태**: `초안` / `검증됨(YYYY-MM-DD)` / `막힘(사유)`. 누가 언제 실제로 돌려 봤는지 남겨요.
- **절차**의 단계마다 권한 등급을 붙여요: `[찾아보기]` `[채워 두기]` `[돈 내기]` `[연락하기]`

## 안전 규칙 (테스트로 검사해요)

- 절차의 모든 단계에 권한 등급이 있어야 해요.
- 캡차·보안문자·본인인증을 풀거나 우회하라는 지시, 비밀번호·카드 번호·인증번호를 입력하라는 지시는 넣을 수 없어요. 그런 단계는 "사람에게 넘긴다(`browser_handoff`)"로 적어요.
- 스킬은 승인 게이트를 끌 수 없어요. 결제·주문·보내기 같은 버튼은 스킬에 뭐라고 적혀 있든 두리 본체가 막아요.
- 반복 조회 간격을 적고 지켜요(기본 1분 이상).

연결 카드(`connect.json`)는 쇼핑·장보기·여행·항공·예매·통신사 등 84개 서비스에 있어요. 절차(`SKILL.md`)가 있는 건 위 표의 서비스뿐이에요.

준비 중인 초안 40여 개(SRT, 코레일, 홈택스, 쿠팡, 캐치테이블 …)를 차례로 옮겨요. 옮겨서 실제로 돌려 보고 `검증됨`으로 올리는 일이 좋은 첫 기여예요.
