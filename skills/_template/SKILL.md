# 서비스 이름

| 항목 | 내용 |
|---|---|
| 상태 | 초안 |
| 주소 | https://… (로그인 화면: https://…) |
| 로그인 | 아이디/비밀번호, 소셜(네이버·카카오), 본인인증 여부 |
| 차단 위험 | 낮음 / 보통 / 높음 — 근거 |
| 반복 조회 간격 | 예: 1분 이상 |
| 공식 API·앱 링크 | 있으면 적기 |

## 할 수 있는 일

| 일 | 등급 | 비고 |
|---|---|---|
| 예: 시간표·잔여석 조회 | 찾아보기 | |
| 예: 예매(결제 전까지) | 채워 두기 | 결제 시한 있음 |
| 예: 결제 | 돈 내기 | 마지막 버튼은 사용자가 |

## 사용자에게 먼저 확인할 것

- 날짜·시간·인원·좌석 등 빠지면 안 되는 값

## 절차

### 1. 로그인 확인
- [찾아보기] 화면 오른쪽 위에 이름·'마이'가 보이면 로그인 상태. '로그인' 버튼이 보이면 두리 금고(`browser_login`)에 있는지 보고, 없으면 사람에게 넘긴다(`browser_handoff`).

### 2. …
- [등급] 무엇을 누르고 무엇을 확인하는지. 화면에 보이는 글자 그대로 적는다(예: 버튼 '조회하기').

## 결과 보고

- 사용자에게 보여 줄 내용(필수 값).

## 막힐 때

- 캡차·본인인증·점검 시간·대기열 등 흔한 상황과 대응. 캡차·본인인증은 항상 사람에게 넘긴다.

## 하지 말 것

- 약관상·안전상 금지.

## 참고
